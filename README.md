# Hotel Booking Cancellation Analysis

## 📊 Project Overview

I created this project to analyze hotel booking and cancellation data and understand the factors related to booking cancellations.

The analysis focuses on guest type, room type, monthly booking trends, and the difference between total bookings and cancelled bookings. I also created an interactive dashboard to make the analysis easier to understand.

## 🎯 Objective

The main objectives of this project were to:

* Analyze the total number of hotel bookings
* Understand the overall cancellation rate
* Compare bookings and cancellations by guest type
* Compare bookings and cancellations by room type
* Analyze booking and cancellation trends by month
* Compare cancellations between City Hotel and Resort Hotel
* Understand how booking patterns change across different years

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Dashboard
* Data Cleaning and Analysis

## 📌 Dashboard Overview

The dashboard contains:

* Total Bookings
* Total Cancellations
* Booking distribution by hotel type
* Cancellation distribution by hotel type
* Bookings and cancellations by guest type
* Bookings and cancellations by room type
* Monthly booking and cancellation analysis
* Year-wise filtering using a slicer

### Key Numbers

* **Total Bookings:** 119,390
* **Total Cancellations:** 44,225

## 🔍 Key Insights

### 1. Hotel Type

City Hotel had a higher number of bookings and cancellations compared with Resort Hotel.

### 2. Guest Type

Couples contributed the highest number of bookings among the guest types shown in the dashboard. Their cancellation count was also higher compared with family and single guests.

### 3. Room Type

The desired room type had significantly more bookings and cancellations compared with the undesired room type.

### 4. Monthly Trends

The number of bookings increased from July and reached higher levels around September and October. The cancellation pattern also changed across the months.

### 5. Cancellation Analysis

Out of 119,390 total bookings, 44,225 were cancelled. This shows that cancellations were a significant part of the overall booking data.

## 💡 Recommendations

Based on the analysis:

* Monitor cancellation patterns for City Hotel more closely.
* Analyze why certain guest types have higher cancellation numbers.
* Focus on understanding demand for the most preferred room types.
* Use monthly booking trends to improve seasonal planning.
* Consider cancellation policies or targeted offers to reduce avoidable cancellations.


## 📈 Conclusion

This project helped me practice data cleaning, Pivot Tables, Pivot Charts, and dashboard creation in Excel.

The analysis provided insights into hotel bookings and cancellations based on hotel type, guest type, room type, and monthly trends. The dashboard makes it easier to identify the major patterns and areas that may need further analysis.
